Model 3: RAG + LLMOps

RAG with a hardened prompt (v2), PII redaction, injection guard, cache, relevance gate, tracing and feedback.

LLMOps features

  • PII redaction: phone, email and Aadhaar numbers are masked before the LLM, cache or logs see them.
  • Injection guard: attempts like "ignore previous instructions" are refused without calling the LLM.
  • Cache: repeated questions are answered instantly at zero token cost.
  • Relevance gate: if retrieval is weak (below min_score) the bot abstains instead of guessing.
  • Prompt registry: versioned prompts (v1 → v2) are evaluated before release.
  • Output guardrails: block system-prompt leaks and flag answers without citations.
  • Tracing: every request is logged to SQLite (latency, tokens, flags).
  • Feedback: 👍/👎 per answer closes the improvement loop.

What each layer adds

LLM

Fluent language and reasoning, but no knowledge of CHRIST-specific rules, so it hallucinates confidently. Cheapest and fastest.

+ RAG

Grounds answers in the official knowledge base with citable sources. Accuracy jumps, and answers can be updated by editing documents, with no retraining.

+ LLMOps

Makes it safe and operable: guardrails (PII, injection, abstain), cache, versioned prompts, tracing, feedback and evaluation-gated releases.
